# Cyber Shujaa - Security Analyst Track 🛡️

This repository contains my personal notes, lab walkthroughs, assignments, and hands-on reports for the **Cyber Shujaa Security Analyst Track** — a practical cybersecurity training program focused on building real-world skills for roles such as SOC Analyst, Threat Hunter, Vulnerability Analyst, and Junior Pentester.

> **Status**: Under active development

---

## 📋 Course Overview

The track is structured into weekly modules covering foundational to intermediate cybersecurity topics:

| Week | Module                              | Focus Areas |
|------|-------------------------------------|-------------|
| 1    | Computing Essentials                | Linux, Windows, Web Requests, Intro to Web Apps |
| 2    | Cyber Security Essentials           | MITRE ATT&CK, Core Concepts, Assignments |
| 3    | Reconnaissance and OSINT            | Passive & Active Recon, Python Scripting |
| 4    | Scanning and Enumeration            | Networking, DNS, Service Enumeration |
| 5    | Vulnerability Assessment            | Scanning, Threat Intelligence |
| 6    | Access Control Security             | Active Directory, Authentication |
| 7    | Web Application Security            | OWASP Top 10, Web Attacks |
| 8    | Database Security                   | SQL Injection, DB Hardening |
| 9    | Wireless Network Security           | Wi-Fi Hacking, Wireless Attacks |
| 10   | Security Operations and Monitoring  | SIEM, SOC Processes |
| 11   | Digital Forensics                   | Windows & Memory Forensics |
| 12   | Malware Analysis                    | Static & Dynamic Analysis, THM Rooms |
