# Junior Security Analyst Intro
## Introduction
Junior Security Analyst, a Triage Specialist. What this means is that the role is all about monitoring systems for any security incidents and report them to senior security analyst for further investigation.

The responsibilities for a Junior Security Analyst or Tier 1 SOC Analyst include:
- Monitorandinvestigate the alerts
- Configure andmanagethesecurity tools
- Developandimplement basic Intrusion Detection System signatures
- Participate in SOC working groups, meetings
- Createtickets and escalate the security incidents to the Tier 2 and Team Lead if needed

Required qualifications (most common):
- 0-2yearsofexperience with Security Operations
- Basicunderstanding of Scripting/programming skills are a plus
