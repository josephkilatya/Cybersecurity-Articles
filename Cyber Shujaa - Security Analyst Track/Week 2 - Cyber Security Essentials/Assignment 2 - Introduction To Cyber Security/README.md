# Introduction To Cyber Security 
## Introduction 
Understanding various paths in cyber security is a crucial thing for upcoming cyber security professionals to pick and explore.  

In this module, we are introduced to offensive security, web application security and digital forensics. Offensive security employs real world hacking scenarios by ethical hackers to identify vulnerabilities in systems for remediation purposes before they are exploited by attackers. Web application security entails finding vulnerabilities in web applications in order to patch them. Digital forensics, on the hand is the application of science to investigate crimes and establish facts.  

The module also covers some challenges/labs to solve while learning about the areas mentioned above.
